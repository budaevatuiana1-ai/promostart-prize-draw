# ПромоСтарт — генератор победителей

## Назначение приложения

Небольшое веб-приложение для наглядного выбора победителей по номерам участников.

Пользователь указывает количество участников — приложение случайным образом выбирает номер от 1 до указанного значения, крупно показывает победителя и добавляет его в список. Можно разыгрывать несколько призов подряд: уже выигравшие номера исключаются из дальнейшего розыгрыша.

## Учебный пример задачи

Это учебный пример из домашнего задания, а не описание реального клиентского заказа.

Маркетинговое агентство регулярно проводит розыгрыши среди подписчиков брендов-клиентов. Раньше победителей выбирали вручную, из-за чего у участников возникали сомнения в объективности результатов.

Нужно было создать простой способ проводить розыгрыши наглядно и удобно, в том числе разыгрывать несколько призов подряд.

## Решение

Создано небольшое веб-приложение, в котором пользователь вводит количество участников.

Приложение случайным образом выбирает номер от 1 до указанного количества участников, крупно показывает победителя и добавляет его в список.

При выборе следующего победителя уже выигравшие номера исключаются из дальнейшего розыгрыша.

## Возможности

- ввод количества участников;
- случайный выбор победителя;
- крупное отображение выигравшего номера;
- несколько розыгрышей подряд без повторов;
- список всех победителей текущего розыгрыша;
- начало нового розыгрыша с очисткой предыдущих результатов;
- понятные сообщения об ошибках ввода;
- блокировка поля количества участников на время розыгрыша;
- защита от случайного двойного клика (повторное нажатие кнопки в течение 0,3 секунды игнорируется).

## Кому может пригодиться

- маркетологам и SMM-специалистам для розыгрышей в соцсетях;
- администраторам мероприятий и организаторам небольших акций;
- преподавателям и студентам, например для жеребьёвки в аудитории;
- модераторам сообществ, которым нужно выбрать несколько победителей без повторов.

## Как провести розыгрыш: пошаговый пример

1. Открыть приложение — опубликованную версию по ссылке ниже или локальный файл `index.html` (см. раздел «Как открыть приложение на компьютере»).
2. В поле «Количество участников» ввести целое положительное число от 1 до 100 000, например `30`.
3. Нажать кнопку «Выбрать победителя». Можно также нажать Enter, пока курсор находится в поле ввода.
4. Дождаться результата: номер победителя появится крупно в блоке «Победитель» и в списке победителей.
5. Нажимать кнопку ещё раз для следующего приза — каждый раз выбирается новый номер, уже выигравшие не повторяются.
6. Когда все участники выиграли, кнопка становится неактивной и появляется сообщение «Все участники уже выиграли».
7. Нажать «Новый розыгрыш» и подтвердить очистку в системном окне браузера — список победителей очищается, поле ввода разблокируется, можно начать заново.

## Использованные технологии

HTML, CSS, JavaScript — без фреймворков и сторонних библиотек, без серверной части.

## Структура проекта

- `index.html` — разметка интерфейса: поле ввода, кнопки, блок победителя, список победителей;
- `style.css` — оформление страницы;
- `app.js` — логика приложения: проверка ввода, выбор победителя, список победителей, сброс розыгрыша;
- `README.md` — описание проекта.

## Как открыть приложение на компьютере

1. Скопировать папку проекта на компьютер.
2. Открыть файл `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Edge).
3. Установка и сборка не нужны: приложение работает как обычная статическая страница и запускается без интернета.

## Ограничения приложения

Все ограничения следуют из текущего кода:

- Максимум 100 000 участников — константа `MAX_PARTICIPANTS` в `app.js`. При большем числе выводится сообщение об ошибке.
- Принимаются только целые положительные числа: дробные, отрицательные, нулевые значения и всё, что не состоит из цифр, отклоняются с сообщением об ошибке.
- Результаты не сохраняются: нет сервера и нет localStorage, поэтому после перезагрузки страницы список победителей и ввод сбрасываются.
- Случайность обеспечивается встроенным `Math.random()`. Это не криптографически защищённая генерация, приложение не сертифицировано и не предназначено для официальных лотерей или юридически значимых розыгрышей.
- Поле количества участников блокируется после начала розыгрыша; изменить число можно только начав новый розыгрыш.
- Повторное нажатие кнопки «Выбрать победителя» в течение 0,3 секунды после выбора игнорируется — защита от случайного двойного клика.
- Сброс розыгрыша требует подтверждения через системное окно браузера; после подтверждения отменить очистку нельзя.
- Список победителей выводится целиком, без постраничного вывода: при очень большом числе победителей список будет длинным.
- Данные доступны только на той странице, где запущен розыгрыш, — приложение рассчитано на одного ведущего на одном устройстве.
