# ПромоСтарт — генератор победителей

## Задача

Маркетинговое агентство регулярно проводит розыгрыши среди подписчиков брендов-клиентов. Раньше победителей выбирали вручную, из-за чего у участников возникали сомнения в объективности результатов.

Нужно было создать простой способ проводить розыгрыши наглядно и удобно, в том числе разыгрывать несколько призов подряд.

## Решение

Создано небольшое веб-приложение, в котором пользователь вводит количество участников.

Приложение случайным образом выбирает номер от 1 до указанного количества участников, крупно показывает победителя и добавляет его в список.

При выборе следующего победителя уже выигравшие номера исключаются из дальнейшего розыгрыша.

## Возможности

- ввод количества участников;
- случайный выбор победителя;
- крупное отображение выигравшего номера;
- несколько розыгрышей подряд без повторов;
- список всех победителей текущего розыгрыша;
- начало нового розыгрыша с очисткой предыдущих результатов.
